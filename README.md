## Proyectos

### [Retail Lab — Ventas & Customer Experience](https://github.com/PaulaCordobesFraga/Retail-Lab-Excel)

Caso práctico de análisis comercial con **1.500 pedidos simulados** de una tienda de moda. Un libro de Excel con **cuatro hojas, siete gráficos y cinco tablas** conecta las ventas netas, los descuentos y las devoluciones con un simulador de promociones. Permite comparar tienda y canal online y estudiar cuánto habría que vender para mantener la contribución tras un descuento.

[![Resumen del proyecto Retail Lab en Excel](https://paulacordobesfraga.github.io/retail-excel-preview.png)](https://paulacordobesfraga.github.io/retail-lab/Retail-Lab-Excel.xlsx)

[Descargar Excel](https://paulacordobesfraga.github.io/retail-lab/Retail-Lab-Excel.xlsx) · [Explorar el repositorio](https://github.com/PaulaCordobesFraga/Retail-Lab-Excel)

Datos simulados de enero a junio de 2026. La contribución es parcial y el simulador calcula un umbral contable; no mide el retorno real de campañas ni predice la demanda.
